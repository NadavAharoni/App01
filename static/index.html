The boring parts, already working

Auth, database and deployment are solved. You start at the interesting part.

Authentication

Sign in with Google, or with email and password. The session is a signed JWT in an HttpOnly cookie, never a token sitting in local storage.

Managed Postgres

A real Neon database with a users table created on startup. Scales to zero while nobody is looking.

Deploys to Cloud Run

Containerised, capped at one instance, scaling to zero. A live demo costs cents a month, and the whole thing stays yours.

Small enough to read in one sitting

Under a thousand lines of Python across six files. No framework layered on the framework, no generated code you are afraid to touch. Open it, read it, change it.

  • ✓ FastAPI and async SQLAlchemy
  • ✓ Neon Postgres over asyncpg
  • ✓ Google OAuth 2.0, identity scopes only
  • ✓ Tailwind from a CDN, so there is no build step
# run it locally
python -m uvicorn main:app --reload --port 8080
# ship it — a push to main builds and deploys
git push origin main
